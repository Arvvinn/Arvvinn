# Profile maintenance

This is the public GitHub profile README for **Arvvinn / Asuka**.

- `README.md`: profile text, project links and light/dark contribution images.
- `assets/hero.svg` and `project-*.svg`: custom vector artwork generated by `scripts/build_profile.py`.
- `assets/signals.svg`: real GitHub public repository metrics, refreshed daily around 02:23 UTC / 10:23 China time. GitHub may delay scheduled runs.
- `assets/toolkit.svg`: locally stored [Skill Icons](https://github.com/tandpfun/skill-icons) artwork fetched from `https://skillicons.dev/icons?i=ts,js,python,java,vue,spring,mysql,cpp,git&theme=dark&perline=9`.
- `assets/contributions*.svg`: animated contribution graph generated with [Platane/snk](https://github.com/Platane/snk).

Use **Actions → Refresh profile widgets → Run workflow** to refresh manually. The workflow uses the built-in repository token; no personal access token or external widget hosting is needed.

The statistics exclude private and forked repositories. Stars are the sum of public owned repository stars. Language distribution counts each repository's primary language, rather than byte volume or skill proficiency. The profile repository itself is included in the public repository count. Contribution snake data follows GitHub's visible contribution calendar.

To regenerate static cards and public statistics locally:

```sh
python scripts/build_profile.py
```

Python 3.12+ and network access to GitHub are required; the script uses only the standard library. Optionally set `GH_TOKEN` for a higher API limit. The script never writes the token to files or includes private repository information.

Project descriptions are based on the linked public READMEs. FoodGlass is a prototype; Harness Lab is a personal learning project based on upstream code, with no claim of Anthropic affiliation; VoiceLog is an interactive UI demo with sample data, not a connected AI service.
